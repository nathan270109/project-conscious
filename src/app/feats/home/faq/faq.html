Analisar repositório
O que o Project Conscious analisa?

O Project Conscious transforma sinais do seu repositório em uma visão clara da saúde do software. Ele considera dimensões como documentação, organização do código, testes, acessibilidade e manutenibilidade para destacar riscos, evidências e prioridades.

Preciso conectar o GitHub para usar?

Não. No MVP, basta informar o repositório que deseja analisar. O processo foi pensado para ser rápido, simples e sem configurações complexas.

Como o Conscious Score é calculado?

Cada dimensão recebe uma nota de 0 a 100. O Conscious Score é calculado pela média dessas avaliações, gerando uma pontuação única que representa a saúde geral do projeto.

E se eu não quiser seguir depois?

Sem problema. Você pode encerrar a análise quando quiser. O MVP foi desenvolvido para permitir explorar os resultados sem exigir continuidade no processo.
